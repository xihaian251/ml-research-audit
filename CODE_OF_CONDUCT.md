# Code of Conduct

## Our expectation

Be precise, be kind to people's work, and separate a finding about evidence from a judgement about a
person. This project's subject matter is published research, which means every audit touches someone's
career. The tools refuse to render verdicts on papers; the community is expected to extend the same
discipline to each other.

Concretely:

- Critique an artifact, a rule, or a document — never a researcher's competence or honesty.
- Report what you observed with a command and a digest. "This is wrong" without a reproduction is not
  feedback, it is noise.
- Do not publish someone else's unpublished work, private data, or manuscript text as an example of a
  finding.
- `INCONCLUSIVE` is a normal outcome. Treat a gap in your own artifacts as information, not as a
  failure to defend.
- Assume the author of a project under audit did not record something because they had no reason to,
  not because they were hiding it. The tools do not distinguish those cases, and neither should a
  discussion.

Behaviour that is not acceptable: harassment, personal attacks, publishing identifying details of a
dataset or manuscript you are not entitled to share, misrepresenting what these tools claim (including
quoting them as proof that a paper is fraudulent or that a result is reproduced), and bad-faith
moderation of other participants.

## Reporting

Open a private security-style advisory or a normal issue in the repository where the behaviour occurred,
naming the thread. This project has **no code of conduct committee** — there is one maintainer and
countless fewer participants than would justify a committee. That is a real limitation: complaints
about the maintainer cannot be handled by the maintainer with any legitimacy. If that happens, the
honest options are GitHub's platform reporting tools for the account, or forking the project and
running your own.

## Scope

Applies in all project spaces: issues, pull requests, discussions, case-study submissions, and any
representation of the project in public.
